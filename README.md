
# Student Grade Calculator 📝

## About Project
This is a simple Python project that calculates
student total marks, percentage and grades.

## Features
- Takes student name as input
- Accepts marks of 5 subjects
- Calculates total marks
- Calculates percentage
- Displays grades based on percentage

## Technology Used
- Python 3

## How to Run

1. Install Python.
2. Download this repository.
3. Open terminal in project folder.
4. Run the following command:

python grade_calculator.py

## Grading System

| Percentage | Grade |
|---|---|
| 90% and above | A |
| 75% - 89% | B |
| 60% - 74% | C |
| 40% - 59% | D |
| Below 40% | Fail |
